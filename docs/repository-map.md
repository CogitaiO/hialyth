# Навигация по репозиторию

Снимок организации после сверки локальной работы с GitHub, 2026-11-15.
Правила работы с Git находятся в [`AGENTS.md`](../AGENTS.md), состояние продукта —
в [`README.md`](../README.md) и [`ROADMAP.md`](../ROADMAP.md).

## Ветки

| Ветка | Назначение |
|---|---|
| `master` | Опубликованная линия; синхронизирована с `origin/master`, без автоматического включения новой Android-работы |
| `develop` | Общая база дальнейшей разработки: опубликованная история, локальная база и сохранённая Android-адаптация |
| `chore/repository-hygiene` | Сверка историй, исключение локальных артефактов и навигация по репозиторию; включена в `develop` |
| `feat/android-mobile` | Сохранённый этап Android-адаптации; отдельный зарегистрированный worktree |
| `backup/master-before-sync` | Историческая резервная точка до прежней синхронизации; не база новых задач |

Промежуточные локальные ветки desktop-этапов удалены только после проверки, что
их коммиты входят в общую базу. Старые удалённые ветки не удалялись.
История релиза `v0.1.0` не переписывалась.

Новая независимая задача может начинаться с актуальной `develop`:

```bash
git fetch origin
git status --short
# При чистом рабочем дереве:
git switch develop
git pull --ff-only
git switch -c fix/short-task-name
# После изменений и проверок — выборочное добавление файлов, коммит и пуш:
git add -- path/to/changed-file
git commit -m "fix: describe the change"
git push -u origin HEAD
```

коммитом `139fb88`; они доступны в истории Git. При сведении веток это удаление
сохранено, чтобы не возвращать устаревшие документы как действующие.

## Что осталось только локально

- `.gitignore` исключает сборки, отчёты, DevTools-настройки и резервные копии
  `AGENTS.md`. Сгенерированные `ios/Flutter/Generated.xcconfig`,
  `flutter_export_environment.sh` и `ephemeral/` больше не отслеживаются;
  в основном рабочем каталоге их файлы оставлены на диске.
- В `.git/info/exclude` этой копии исключены `opencode.json` с локальной
  MCP-конфигурацией и `t` с захваченным терминальным выводом. Они не публикуются.
- Исторический stash `WIP before syncing with GitHub` сохранён без применения и
  удаления: его содержимое не считается автоматически актуальной реализацией.
- В локальной Git-конфигурации используются `push.default=simple`,
  `pull.ff=only` и `fetch.prune=true`; глобальные настройки не менялись.

## Сохранённые контрольные точки

- `72d60a4` — прежняя общая локальная desktop/Android-база.
- `568a989` — концепты иконки и маскота.
- `e9d10c5` — черновики внешней Linux-диагностики.
- `213af16`, `9a34b11`, `9148074` — доступ к Android-документам, мобильные
  экраны, управление плеером и регрессионные тесты соответственно.

Эти коммиты сохраняют уже существовавшую работу. Они не означают, что исправлены
автосканирование при запуске, рывки диалога коллекции или переориентированы релизы:
это отдельные последующие задачи.
