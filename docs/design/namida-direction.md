# Hialyth: направление по референсу Namida

Дата: 2026-11-09. Референс: локальный `../namida`, README и иллюстрация `namida-assets/screenshots/readme/collection_dark_1.webp` и `collection_dark_2.webp`.

## Что изучено

- `lib/ui/pages/home_page.dart`: секции контента с различной иерархией.
- `lib/ui/widgets/library/album_card.dart`: обложка, метаданные, действия и единая поверхность карточки.
- `lib/ui/widgets/player_transport_controls.dart`: отдельные обновления позиции и адаптивная компоновка управления.
- `lib/ui/widgets/custom_widgets.dart`: общие поверхности и короткие fade-переходы.

Реализация Hialyth самостоятельная: сохраняются Flutter/Riverpod/Isar/media_kit, desktop-навигация и сценарии аниме. Глубина строится на обложках, тональных уровнях, масштабе и ритме; blur допускается только в ограниченных областях над видео. Цвет обложки используется как ambient, пользовательский акцент — для действий.

## Видимый результат

1. **Библиотека.** Крупная карточка продолжения просмотра, секция коллекции, сортировка и Grid/List с сохранением выбора, Ctrl+F, осмысленные состояния импорта.
2. **Details.** Compact-раскладка с общей прокруткой, poster/header, крупное основное действие, раскрываемое описание, файл и прогресс у эпизода, missing-состояние, полный выбор статуса. Фон через градиенты без полноэкранного BackdropFilter.
3. **Плеер.** Загрузка локального видео до сети, отмена устаревших запросов, восстановление после ошибок. Фиксированные места транспорта, millisecond timeline, ограниченные тёмные поверхности; стоимость UI/raster проверяется отдельно от golden-снимков.
4. **Настройки.** Appearance / Playback / Library / Integrations / Advanced; доступные переключатели и защищённая очистка БД.

## Проверки

- Изолированные Isar-регрессии: коллизии, одновременные изменения, несколько источников, исчезнувшие файлы.
- Backend-регрессии плеера: закрытие/смена запроса во время загрузки, ошибки, retry, языки и RPC.
- Экраны при 840×560 и 1280×720; увеличение текста, клавиатура и сохранение выбора.
- Analyze, полный suite и Linux release build. Windows требует отдельной сборки на соответствующей платформе.
- Golden подтверждает раскладку и внешний вид, но не FPS. Реальная плавность должна подтверждаться profile-замерами UI/raster на целевой машине и видео.

## Профилирование на целевой машине

`flutter run --profile -d linux --dart-define=profileFrames=true`

Открыть видео, повторить появление управления, выезд sidebar, перемотку, PiP и
переход Library → Details. Каждые 120 кадров журнал содержит p95 времени UI/raster
и число кадров выше 16,67 ms. Измерять на одинаковом видео и размере окна, отдельно
с включённой и уменьшенной прозрачностью. Статические golden-снимки не доказывают FPS.

Флаг `designV2=false` отключает новый theme/resume/ambient/glass-слой; сортировка,
адаптивность и исправления данных остаются включёнными. Это безопасный упрощённый
режим представления, а не возврат к ошибкам старого приложения.

## Результат проверки этапов

- Analyze: без замечаний.
- Полный набор: 70 тестов прошли.
- Linux release: обычный режим собран; упрощённый режим `designV2=false` собран.
- Снимки Library, Details и Settings проверены при 840×560 и 1280×720.
- Для Details проверены длинный заголовок, масштаб текста 200%, раскрытие описания
  и missing-файл; для библиотеки — Ctrl+F, сортировка, сохранение Grid/List.
- Удаление библиотеки проверено на подставном репозитории: отмена и неверное
  подтверждение не вызывают очистку.
- Фактические UI/raster замеры на целевом GPU и сборка на Windows остаются
  отдельной аппаратной проверкой.
