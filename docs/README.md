# Hialyth — документация

Документы фиксируют продуктовые и дизайнерские решения до начала визуального редизайна.

| Документ | Статус | Назначение |
|---|---|---|
| [`ux/ux-ia-contract.md`](ux/ux-ia-contract.md) | Draft v0.1 | Сценарии, информационная архитектура, состояния, навигация, адаптивность |
| [`design/design-contract.md`](design/design-contract.md) | Draft v0.1 | Визуальный язык, токены, компоненты, motion, accessibility, glass |
| [`architecture/i18n.md`](architecture/i18n.md) | Proposal v0.1 | Локализация, ARB, смена языка интерфейса и хранение выбора |

## Порядок работы

1. Утвердить UX/IA-контракт и дизайн-контракт.
2. Закрыть открытые решения в конце каждого документа.
3. Сделать foundation PR без визуальных изменений: тема, типографика, motion, surfaces, breakpoints, component themes.
4. Добавить Design System Gallery и golden-тесты.
5. Провести glass spike на поверхностях плеера.
6. Переходить к постепенному редизайну экранов за feature flag.

## Границы этапа

- Не меняем стек: Flutter, Isar, media_kit, Riverpod.
- Не начинаем мобильную реализацию.
- Не переименовываем legacy-идентификаторы (`nekaido_pre`, `NekaidoLogs`) в рамках этого этапа.
- Не делаем big-bang редизайн: только поэтапная миграция после утверждения контрактов.

## Состояние реализации — 2026-11-08

- Foundation: dark theme, локальные шрифты, motion/surface/breakpoint-токены,
  английский ARB, debug gallery и golden-снимки добавлены. Миграция экранов
  на токены ещё не завершена.
- Settings → Appearance → Accessibility: сохраняемые Reduce transparency и
  Reduce motion. Доступность переключателей и сохранение выбора проверяются
  на размерах 840×560 и 1280×720; compact использует горизонтальные вкладки.
- Library: адаптивная навигация, подписи и счётчики на широком окне, drawer на
  compact, добавление папки в top bar, очистка поиска, отдельные пустые состояния,
  тональные карточки с focus/hover и действиями воспроизведения.
- Player: плавающая нижняя панель с fallback без blur, локальное сглаживание
  миллисекундного прогресса, мгновенная перемотка, transform-анимация sidebar.
  Video shell не подписан на изменения позиции и громкости целиком.
- Glass: sidebar, skip, PiP и нижняя панель; одновременно не более двух blur-
  поверхностей. Добавлены проверки контраста на белом/чёрном фоне и композиции
  внутри opacity. Профилирование на реальном видео ещё не выполнено; отсутствие
  пропусков кадров на конкретном GPU не подтверждено.
- Следующие части UX-контракта: сортировка и Grid/List с сохранением выбора,
  раскрываемые подборки в sidebar, адаптивные Details, состояния ошибок плеера,
  отдельный раздел Integrations. Контракты целиком ещё не реализованы.
